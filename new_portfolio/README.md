# Harsh Khamkar — Portfolio

World-class portfolio for **Harsh Khamkar** — Data Scientist, AI/ML Engineer, and Analytics Leader.

## Tech Stack

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4** + glassmorphism design system
- **Framer Motion** + **GSAP** animations
- **Three.js** / React Three Fiber / Drei (3D hero & skill spheres)
- **Recharts** data visualizations
- **MDX** ready for content
- Full **SEO** + JSON-LD structured data

## Getting Started

> **Tip:** If `npm install` is very slow, move this folder **outside OneDrive** (e.g. `C:\dev\new_portfolio`) — synced folders often block `node_modules` writes.

```bash
npm install --strict-ssl=false
npm run dev
```

On university/corporate networks you may need `--strict-ssl=false` due to SSL inspection proxies.

Open [http://localhost:3000](http://localhost:3000).

## Customize

| File | What to update |
|------|----------------|
| `src/lib/data/site.ts` | Email, LinkedIn, GitHub, resume URL |
| `src/lib/data/projects.ts` | Project copy, metrics, tech stack |
| `src/lib/data/skills.ts` | Skill levels and categories |
| `public/resume/Harsh_Khamkar_Resume.pdf` | Your actual resume PDF |

## Resume

Place your PDF at `public/resume/Harsh_Khamkar_Resume.pdf` for the download button.

## Deploy
